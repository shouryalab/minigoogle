Here's what this site does

Mini Google is a tiny search engine that runs on a fake web. Search any word and it makes up some pages about it, then ranks them two different ways, side by side.

The old way counts how many times a page repeats your word.
PageRank counts who links to the page, and how important those pages are.

New here? Start with pizza and watch the spam page fall. Then try any other word.

Old method: count the keywords

PageRank: count the votes

A link is a vote. Votes from important pages count for more.

The tiny web behind the search

Arrow A → B means "page A links to page B". Bigger circle = higher PageRank. A red circle has no arrows pointing at it, so nobody vouches for that page.

PR(p) = (1 - d) / N + d × sum of PR(q) / links(q)
d = 0.85, N = number of pages, q = every page linking to p
